# 9. MCP

Agents can price options through [MCP](https://modelcontextprotocol.io) without writing Python.
The server is stdlib-only — `pip install blackscholes` is enough.

### Run

```commandline
python -m blackscholes.mcp
```

or `blackscholes-mcp` after install.

### Client config

```json
{
  "mcpServers": {
    "blackscholes": {
      "command": "python",
      "args": ["-m", "blackscholes.mcp"]
    }
  }
}
```

With `uvx` (no local install):

```json
{
  "mcpServers": {
    "blackscholes": {
      "command": "uvx",
      "args": ["--from", "blackscholes", "blackscholes-mcp"]
    }
  }
}
```

### Tools

**instruments** lists kinds and constructor params.

**price** takes `kind` plus those params.
`fields` is `price` (default), `core` (price + delta/gamma/vega/theta/rho), `all`, or a comma-separated method list (`price,delta,charm`).

Same numbers as the Python classes:

```
kind=call  S=55  K=50  T=1  r=0.0025  sigma=0.15
## {"price": 6.339414}
```

```
kind=call  fields=core  S=55  K=50  T=1  r=0.0025  sigma=0.15
## {"price": 6.339414, "delta": 0.766408, "gamma": 0.037125, "vega": 16.845454, "theta": -1.352942, "rho": 35.813015}
```

```
kind=straddle_long  fields=price,delta  S=55  K=50  T=1  r=0.0025  sigma=0.15
## {"price": 7.553985, "delta": 0.532816}
```

Class names work as `kind` too (`BlackScholesCall`).
Params can be top-level arguments or a nested `params` object.

### Kinds

| kind | class | params |
| --- | --- | --- |
| `call` / `put` | `BlackScholesCall` / `Put` | `S, K, T, r, sigma, q` |
| `black76_call` / `black76_put` | `Black76Call` / `Put` | `F, K, T, r, sigma` |
| `binary_call` / `binary_put` | `BinaryCall` / `Put` | `S, K, T, r, sigma` |
| `straddle_long` / `straddle_short` | `BlackScholesStraddle*` | `S, K, T, r, sigma, q` |
| `strangle_long` / `strangle_short` | `BlackScholesStrangle*` | `S, K1, K2, T, r, sigma, q` |
| `butterfly_long` / `butterfly_short` | `BlackScholesButterfly*` | `S, K1, K2, K3, T, r, sigma, q` |
| `iron_condor_long` / `iron_condor_short` | `BlackScholesIronCondor*` | `S, K1, K2, K3, K4, T, r, sigma, q` |
| `iron_butterfly_long` / `iron_butterfly_short` | `BlackScholesIronButterfly*` | `S, K1, K2, K3, T, r, sigma, q` |
| `bull_spread` / `bear_spread` | `BlackScholesBullSpread` / `BearSpread` | `S, K1, K2, T, r, sigma, q` |
| `calendar_call_spread` / `calendar_put_spread` | `BlackScholesCalendar*Spread` | `S, K1, K2, T1, T2, r, sigma, q` |

Call `instruments` for the live list.
European options only — see [8. Disclaimer](https://carlolepelaars.github.io/blackscholes/8.disclaimer).
