# 9. MCP

If you can write Python, import the classes. This page is for chat hosts
(Claude, Cursor, Grok, …) that cannot.

```commandline
python -m blackscholes.mcp
```

```json
{
  "mcpServers": {
    "blackscholes": {
      "command": "python",
      "args": ["-m", "blackscholes.mcp"]
    }
  }
}
```

Two tools. **`instruments`** lists kinds. **`price`** takes `kind` plus the
usual market params and returns price + core greeks (`all_greeks=true` for the rest).

```
kind=call  S=55  K=50  T=1  r=0.0025  sigma=0.15
## {"price": 6.339414, "delta": 0.766408, "gamma": 0.037125, "vega": 16.845454, "theta": -1.352942, "rho": 35.813015}
```

Same numbers as `BlackScholesCall(...).price()` / `.get_core_greeks()`.
Kinds: `call`, `put`, `black76_call`, `black76_put`, `binary_call`, `binary_put`,
`straddle_long` / `_short`, `strangle_*`, `butterfly_*`, `iron_condor_*`,
`iron_butterfly_*`, `bull_spread`, `bear_spread`, `calendar_call_spread`,
`calendar_put_spread`.
